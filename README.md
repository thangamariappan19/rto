# Hybrid RTO Predictive Analytics 🏢🤖

An enterprise-grade forecasting system to predict office occupancy in the age of hybrid work.

## ✨ Features
- **Multi-Modal Forecasting:** Combines badge swipes, calendar events, and weather signals.
- **Premium Dashboard:** Real-time visualization of occupancy trends using Angular & Chart.js.
- **Privacy by Design:** K-anonymity and differential privacy protocols for employee data.
- **Research Documentation:** Full whitepaper outline and problem formulation for R&D publication.

## 🛠️ Project Structure
- `/backend`: FastAPI service for serving predictions.
- `/frontend`: Angular dashboard for facilities management.
- `/ml`: Python data models and synthetic data generation scripts.
- `/docs`: Research briefing, architecture, and ethical guidelines.

## 🚀 Getting Started

### Backend (Python)
1. Navigate to `/backend`.
2. Install dependencies: `pip install fastapi uvicorn`.
3. Run the server: `python main.py`.

### Frontend (Angular)
1. Navigate to `/frontend`.
2. Install dependencies: `npm install`.
3. Run the app: `npm start`.
